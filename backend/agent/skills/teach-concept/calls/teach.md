- `example_md`: 150–350 words. **One** complete, realistic worked example (§2, worked examples): a concrete situation, the steps or reasoning in order, and the result, with real numbers, commands or code where the topic has them. Use a different situation from the one the analogy used.
- `diagram_mermaid`: Mermaid source only, no ``` fences, starting with `flowchart`, `graph`, `sequenceDiagram`, `stateDiagram-v2` or `classDiagram`. Show the structure or flow from the explanation (§4.5), not decoration: 4–10 nodes, short labels, quote any label containing punctuation (`A["pool (max 10)"]`). No `click`, no HTML, no styling.
